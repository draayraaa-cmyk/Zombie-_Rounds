# Zombie Round

A small Love2D survival shooter prototype built in Lua.

## Features
- WASD movement
- Mouse aiming and shooting
- Endless zombie waves with round scaling
- Score and health HUD
- Restart with Enter after death

## Run it
1. Install Love2D from https://love2d.org/
2. Open a terminal in this folder
3. Run:

   love .

Or launch the folder with Love2D by dragging it onto the Love2D executable.
